# Sign up for the Exchange

The Hub uses the [JupyterHealth Exchange](xref:jh/glossary#term-exchange) for authentication.
Once you have an Exchange account, logging into the Exchange logs you into the Hub too.
You only need to do this once.

## Get an invite code

Signing up requires an invite code.
Ask for one in the `#jupyterhealth` channel on [Zulip](xref:jh/glossary#term-zulip).

## Create your account

1. Go to the Exchange for your Hub and click {guilabel}`Sign Up`.
   For the demo Hub, this is <https://berkeley-jhe-demo.jupyterhealth.org/>.

   ```{figure} images/exchange-home.png
   :alt: The JupyterHealth Exchange home page with Sign Up and Log In buttons
   :width: 500px
   ```

2. Enter your invite code, email address, and a password, then click {guilabel}`Sign Up`.

   ```{figure} images/exchange-signup.png
   :alt: The Exchange Sign Up form with fields for invite code, email, and password
   :width: 300px
   ```

3. Log in.
   If you see the Exchange dashboard, your account works.

   ```{figure} images/exchange-dashboard.png
   :alt: The Exchange dashboard with a sidebar listing Organizations, Patients, Studies, and more
   :width: 500px
   ```

You're now logged into the Exchange, so you can go straight to the Hub and [launch a session](log-in.md).
